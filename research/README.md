# Research

Research records explain how a guide was established; they are not player instructions.

- [TR3R / Nevada — evidence register and approval scope](tr3r/nevada/README.md)
- [Experiment template](EXPERIMENT_TEMPLATE.md)
- [Content and approval workflow](../content/README.md)

Organize each application under `<game>/<application>/`. Its README lists the
current approved guide, experiment IDs, results and outstanding questions.
New trials go in `experiments/`; superseded records go in `archive/` and remain
linked from the register. Preserve raw observations when conclusions change.
Existing migrated records retain their original notes beneath a standard summary.

This directory is outside the website root, but is still visible in a public
repository. Keep raw runtime logs, save files and machine-specific material in
the local analysis workspace; reference relevant evidence by identifier.
