Read Lara’s state

CE process: tomb123.exe. Module: tomb3.dll. Observed locator:

["tomb3.dll"+3D4D30]+58

Base B points to Lara’s X field, not the start of the entire object structure. All offsets below are relative to B. Multi-byte values are little-endian and interpreted as signed integers.

Source: the locally used ce_lara_resolver.lua. Loading can move B. The resolver detects this and normally requires validation and a bridge reload; its explicit reproduction mode also checks locator and identity fields.

Yaw uses 65536 units per revolution; −3250 is approximately −17.85°. In these measured coordinates, a more negative Y value is higher.

Bridge and reproduction status

The local bridge checks process identity and game focus. It releases held keys on abort. UI timers are used: millisecond arguments are not a frame-accurate guarantee.

SET is a separate research operation. It must not appear in evidence claimed to be a keyboard-only replay. A historical Nevada reference used it at the lower start. The approved Setup revision 1 uses keyboard inputs for positioning and ascent without position or yaw writes.

Local bindings: action E, crouch Y, weapons Space, flare comma, inventory Esc. These are not claimed as default bindings.
