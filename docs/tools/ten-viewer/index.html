Glitch Lab · Level Inspector

Open a local .ten or TR3 .tr2 file or drop it onto the viewer. Files are processed on your device and are never uploaded. No game installation or Python is required.

Supported formats: TEN 1.10.1.0 with embedded PNG textures and TR3 PC (classic level data, including the Remastered .tr2 files). Detection uses the file header. TR1, TR2 and console formats are not yet supported. TR3 uses classic textures and reference poses, not Remastered HD assets. Event volumes are available only in TEN. Limit: 512 MiB input, 384 MiB per unpacked block, 768 MiB total unpacked data.

WASD: fly in the viewing direction. Drag: look. Q/E: down/up. Shift: faster. F: focus selected room. Click the minimap to inspect a sector.

This is a static reference-pose inspection tool. Gameplay, Lua, animation, runtime collision changes and special Lara skinning are not simulated. TEN trigger surfaces show raw indices. TR3 sector inspection also shows decoded floor-data functions and trigger actions. Animated textures and sprites are shown in a reference frame; dynamic collision and engine lighting are not simulated.

The offline download is generated from the same source as the website. Open that HTML file directly in a modern desktop browser.

Glitch Lab · Level Inspector

A browser-based level inspection tool for Tomb Raider Glitch Lab. An independent project; not an official trview, TombEngine or Tomb Raider product.

Level files are processed locally. No game levels, textures or other game assets are included. Rights to user-loaded content remain with their respective owners.
