CASE-0004 — Temple crouch-roll eject

REPRODUCED · analysis

The complete temple crouch-roll eject to the narrow leafy room-28 destination was manually reproduced. A natural near-anchor setup reaches the viable eject position with one ordinary backward hop, and two video-recorded repeats confirm that holding LEFT continuously through the eject produces the same stable room-28 endpoint.

This validates pre-armed recovery for the current session, not starting the existing +22A0 hook after the modal requester is already open.
