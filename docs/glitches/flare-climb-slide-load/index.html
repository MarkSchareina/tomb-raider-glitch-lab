Quick Reproduce

  1. Prepare the crouched state

    At a suitable slope, repeatedly drop and pick up a flare while crouching. Buffer the final pickup through the inventory until Lara visibly drops into the crouch animation. Save that state.

  2. Establish the slide

    Load a prepared starting save at the appropriate opposing slope and actually start sliding.

  3. Load the crouch save

    While sliding, load the prepared crouch save. In the tested routes, this allows Lara to reach the upper surface.

This is the shared sequence, not a universal input recipe. Exact positions, angles, counts and sliding directions belong to each application.

How it works

Why this is one guide

The flare cycle produces the required elevated crouched state. The subsequent slide/load transition completes the route. Slide-load is documented here as a phase of the technique rather than as an independently useful glitch.

Evidence and scope

Successful endpoints have been observed in TR3R. Read-only telemetry confirmed the crouch state and animation. The result depends on the saved state and the surrounding geometry; a high-looking pose alone is insufficient.

The tested installation uses tank controls on Windows. Its exact game build and compatibility with other platforms are not documented yet.
