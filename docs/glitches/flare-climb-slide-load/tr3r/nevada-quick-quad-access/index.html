Setup revision 1 · approved 2026-09-28. Keyboard-only positioning, 10 lower angle buffers, flare climb and visible sink into crouch. The user reported success and adopted this sequence as the Setup. The subsequent slide/load was not separately measured for this revision.

Quick Reproduce

  1. Create the slope save

    Go to the opposing slope used for the slide/load transition. Position Lara so that you can move onto it and start sliding after loading. Save this starting position before leaving the slope. Keep this slope save separate from the elevated crouch save you will create later.

  2. Move to the aligned hollow

    After creating the slope save, move to the hollow and pull up onto the small ledge. Start from the demonstrated aligned position facing the hollow. An arbitrary position in the hollow is not sufficient. Use the image to identify the aligned starting position; numerical reference values are listed under Measurements below.

  3. 4 backward hops, then 1 roll

    Tap Back 4 separate times and let each backward hop finish. Do not press Jump. Perform 1 roll and let it finish.

  4. Walk forward in 3 groups

    Take 9 walking steps in the following sequence:

    1. Hold Walk + Forward for 3 walking steps, release and come to a complete stop.
    2. Hold Walk + Forward for 3 walking steps, release and come to a complete stop.
    3. Hold Walk + Forward for 3 walking steps, release and come to a complete stop.

    Do not walk all 9 steps continuously. After the 3rd group, Lara is at the lower positioning checkpoint, ready for angle adjustment.

  5. Set the lower angle with 10 inventory buffers

    Open the inventory. Perform 1 Left buffer → 1 idle buffer → 6 Left buffers → 2 idle buffers. Do not add extra idle buffers. Each buffer starts and ends in the inventory. A Left buffer holds Left on reopening; an idle buffer uses no direction.

  6. Perform 28 flare pickups

    Draw a fresh flare and immediately start the crouch/drop/pickup chain. Count each pickup. During the 28th pickup, open the inventory before the animation finishes. This is the upper pickup checkpoint for the crouch buffers in the next step.

  7. Buffer until Lara visibly sinks into crouch

    Apply crouch inventory buffers until Lara visibly sinks into a crouched position. The confirmed manual run needed 15 buffers. The count can vary depending on when you paused the pickup, so use the visible sink as your stopping cue.

  8. Save the crouched state

    Save the elevated crouched state separately from the slope save. Remember this crouch save: after loading the slope save and starting to slide, you will load this previously saved state again.

  9. Load the slope save

    Load your prepared save at the opposing slope. Keep the previously saved elevated crouch state available for the final load.

  10. Start sliding

    Move onto the opposing slope and let Lara actually enter the sliding state. Standing at the slope is not sufficient.

  11. While sliding, reload the previously saved crouch state

    While Lara is actually sliding, load the elevated crouch state you saved before loading the slope save. This returns to that earlier saved state with the slide/load transition, used to reach the upper platform.

Result: upper platform reached

After loading the crouch save during the slide, Lara reaches the upper platform beside the fenced compound. Compare your position with the image below.

Details & evidence

What one inventory buffer means

With the inventory fully open, tap Esc and release it. During closing, press Esc again with the required input until the inventory reopens; then release. Use Left for angle buffers, no direction for idle buffers, and Crouch for upper buffers. The tested bridge used parameter 180 ms and a 60 ms initial Esc phase, observed as 2 game frames per buffer. These tool timings are not universal real-time guarantees.

What was confirmed

The agent trial and the player following the instructions reached the same lower position. The 10 lower angle buffers were confirmed automatically and manually. The player confirmed visible sinking after exactly 15 upper crouch buffers; read-only measurements confirmed state 71, animation 222, a 40-unit downward movement and 33 units of wall clearance. The player subsequently reported success and approved this Setup on 28 September 2026.

Slide/load continuation and verification scope

The full sequence is: save the elevated crouch, load the opposing-slope save, start sliding, then reload the previously saved crouch state. The player completed this sequence for the screenshot walkthrough and supplied the final upper-platform image. That final position is visually documented; the slide/load transition itself was not separately measured with telemetry in this capture session. The onward route to the quad remains unverified.

Input-only validation and automation

The confirmed Setup used keyboard inputs without position or yaw writes. The agent did not overwrite saves. The older Lua runner implements historical trials; approval of this manual Setup does not establish live validation of that runner.

Technical reference: pickup timing and buffer counts

The manual run started at pickup frame 8701 and reached crouch after 15 buffers. The automated run started at frame 8693 and needed 19 buffers. These frame numbers come from read-only telemetry and are not visible during normal play. They explain the different counts; the player-facing stopping cue is the visible sink into crouch.
